# Система учета инцидентов

Консольное приложение для регистрации и обработки инцидентов технической поддержки. Исходный сценарий ПР1 развит по требованиям ПР2.

## Возможности

- регистрация и просмотр нескольких инцидентов;
- поиск по названию и описанию;
- фильтрация и сортировка по статусу/приоритету;
- назначение исполнителя и изменение статуса;
- статистика по статусам и приоритетам;
- сохранение и загрузка данных в JSON;
- обработка неверного ввода, поврежденного файла и неизвестного ID.

## Формат данных

Инциденты представлены списком словарей с полями `id`, `title`, `description`, `user`, `executor`, `priority`, `status`, `created_at`. Данные сохраняются в `data/incidents.json` в UTF-8. Статусы: `Новый`, `В работе`, `Решен`, `Закрыт`; приоритет — число от 1 до 3.

## Структура проекта

- `main.py` — запуск, меню и вывод;
- `incidents.py` — бизнес-логика, поиск, фильтрация и статистика;
- `storage.py` — работа с JSON;
- `utils.py` — безопасный ввод;
- `data/incidents.json` — данные;
- `tests/` — тесты pytest;
- `requirements.txt` — инструменты разработки.

## Установка и запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

## Проверка

```bash
pytest
flake8
```

Сохранены и развиты функции ПР1: `get_priority_name()`, `get_incident_status()` и `create_incident()`. Классы не применяются: объектная модель относится к ПР3.
