# Система учета инцидентов

## Назначение

Приложение предназначено для регистрации и первичной обработки инцидентов. Система хранит основную информацию об инциденте, его статусе и назначенном исполнителе.

## Целевая аудитория

* сотрудники технической поддержки;
* системные администраторы;
* исполнители, занимающиеся устранением инцидентов.

## Предметная область

Инцидент — это проблема или событие, нарушающее нормальную работу информационной системы, оборудования или сервиса.

На текущем этапе реализован небольшой сценарий регистрации инцидента и определения его приоритета и статуса.

## Основные сущности

* Инцидент — зарегистрированная проблема.
* Пользователь — человек, зарегистрировавший инцидент.
* Исполнитель — ответственный за устранение инцидента.
* Статус — текущее состояние инцидента.

## Основные функции

* регистрация инцидента;
* определение приоритета инцидента;
* определение его текущего статуса.


## План развития

На следующих этапах планируется:

* разработка веб-приложения;
* подключение базы данных;
* реализация пользователей и исполнителей;
* разработка API;
* контейнеризация приложения;
* настройка CI/CD.
